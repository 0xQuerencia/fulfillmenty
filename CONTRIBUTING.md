# Contributing

Thanks for helping improve Fulfillmenty. The project is being built as an independent, open sourcing utility.

## Before proposing a change

- Open an issue for larger changes so the product and data contracts stay consistent.
- Keep product identity, merchant listing, destination, currency, and observation time explicit.
- Mark all synthetic records and prices as illustrative; never present them as live data.
- Do not add a merchant connector until its access method, terms, rate policy, and redistribution rights have been reviewed.
- Never make a server fetch an arbitrary URL supplied by a contributor.
- Never add participant addresses, payment information, or unredacted receipts to the catalog.

## Pull requests

Describe the user problem, the changed API or data contract, and any security or provenance implications. Keep changes focused and include migration notes for schema changes.

## License status

The project has not selected a license yet. Contributions are welcome for discussion, but the repository does not currently grant reuse rights beyond applicable law. A contribution agreement will be documented when a license is selected.
