# Fulfillmenty dashboard

Next.js frontend for the Fulfillmenty catalog, offer comparison, contribution, moderation, and API reference screens.

Run from the repository root with `pnpm dev`. The browser reads from `NEXT_PUBLIC_API_BASE_URL` (defaults to `http://localhost:4000/v1`). Local contribution and moderation use development-only demo roles; production mutations require scoped API keys.

See the root [README](../../README.md) for database setup and project boundaries.
