# Third-party data notices

## Country and currency reference data

Country and currency reference rows are seeded from [`countries-list`](https://github.com/annexare/Countries), distributed under the MIT License. Its dataset identifies ISO 3166-1 alpha-2 country codes and ISO 4217 currencies; currency minor-unit decimals are used to format prices. The dependency's license is included in the installed package.

The Fulfillmenty project itself has not selected a repository license yet.

## World map

The interactive dashboard map uses the TopoJSON country boundaries from [`world-atlas`](https://github.com/topojson/world-atlas) 2.0.2, derived from Natural Earth 4.1.0. The package is distributed under the ISC license, whose notice is included with the installed package. Natural Earth states that its map data is in the [public domain](https://www.naturalearthdata.com/about/terms-of-use/). Map shading reflects published offer counts when available; otherwise the shown reference coverage is illustrative.
